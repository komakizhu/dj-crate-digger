# Rich mode

`four_views` uses one shared candidate pool and one deep-verification pass. Render four views in the selected locale's fixed shape: style, scene, familiarity/discovery, and dynamic combined. Every view uses the same twelve columns as Brief. The dynamic combined view is the only final source for export, harmonic reorder, and transition advice.

Default targets are ten tracks per specialist view and thirty for the dynamic combined view. The pool goal is `min(max(2 × final_target, final_target + 8, required_unique + 8), 120)`, where `required_unique` is the sum of view slots under the default zero-overlap rule. Each view is unique. Across the full report, use zero overlap by default; at most one recording can appear twice, only when it is verified, has a complete title, ranks strongly in two views, has an independent quality signal, and beats the best unused alternative by the documented margin. Never use a reference artist as an exemption.

Preserve a single continuous final dynamic order and its energy arc. After that view, include the locale's digging-notes heading and exactly one creative transition suggestion sourced only from the dynamic collection. The three specialist views do not receive separate suggestions.

After the complete report, render exactly three localized next-step items. If the user gives a positive harmonic response, reorder only the dynamic combined view with [key-and-sequencing.md](../key-and-sequencing.md); leave the specialist views unchanged. Export only the dynamic combined collection.
