# DJ Crate Digger Skill

面向 DJ、音乐制作人与电子音乐听众的 Agent Skills：把自然语言 Digging 需求转成经过联网搜索、逐曲验证、去重、排序和播放顺序设计的 Markdown 报告。

## Agent Skills 兼容性与来源

本仓库以标准 `SKILL.md` 作为通用入口，`references/` 是按需读取的补充资源；支持 Agent Skills 标准的客户端可以按自身的技能目录发现并加载它。Claude Code、VS Code Agent 等支持该标准的客户端可以复用核心内容，但具体发现目录、权限确认和工具名称由客户端决定。

本版本基于 Codex 版 DJ Crate Digger Skill 修改为 Agent Skills 通用格式。`agents/openai.yaml` 仅是 Codex 的可选 UI 与调用适配层，不包含独有的推荐算法；其他 Agent 可以忽略该目录，直接使用 `SKILL.md` 与 `references/`。不支持 Agent Skills 的客户端需要手动加载 `SKILL.md`，并将搜索、页面核验、文件写入和后台续跑映射到自身能力。

## 本版重点

- 中文 DJ 口语与场景语义归一化，区分参考艺人与专题目标。
- SoundCloud → Apple Music → Spotify 默认链接展示顺序；跨平台发现采用均衡轮询，用户首选、允许和禁用平台可覆盖默认值。
- 候选池按目标数自适应扩展；每首最终曲目逐条打开直接页面核验，播放链接与核验来源分开记录。
- 触发后严格用两轮收集需求：第一轮确认场景、目标国家 / 地区、核心声音方向、歌曲数量或 Set 时长和其他限制；第二轮完成风格、BPM、熟悉度与发现感、时代与经典、输出版本、情绪、能量、平台与链接要求和其他限制。
- 两轮提问在所有环境中采用低自由度的字面模板契约：简体中文逐字保留标题、规则、示例、行内反引号、空行和唯一一个可复制的 fenced Markdown 填写代码块；发送前执行完整性自检。第一轮固定说明复制、自由填写或不填；极速版映射为独立 `fast` 路径，简要版默认输出，用户填写丰富版时才展开四种视角。
- 极速版以单一主导向、最多两个同向查询和一套 60/25/15 轻量排序函数完成首批；首批主动计算预算为约 60 秒（网络等待不计），严格逐曲验证、录音级零重复和三列表输出。请求超过 20 首时，具备中间消息和后台能力的客户端只读取同两条查询的后续结果并按同一评分函数续跑；不具备时明确只能交付首批。真实模型的 12 次冷启动性能验收已定义为后续协议，首批与续跑口径已分开，尚未伪称完成。
- 沟通语言与目标市场分离：标题、问卷、状态和解释跟随当前输入语言；目标国家 / 地区只影响本轮搜索语境与可用性判断，明确市场覆盖语言推断但不持久化。
- 丰富版仍共享同一验证候选池，并保留风格、场景、熟悉度与发现感、动态综合四个视角；简要版采用 Warm Up → Groove → Peak → Closing，并跨段去重；简要版和丰富版主表为 12 列，在 BPM 后加入可靠来源核验的调性，极速版仍为三列。
- 丰富版执行整份报告级录音去重：默认不重复；最多允许一首证据充分的高质量核心曲跨两个视角出现，任何曲目不得出现三次，参考艺人与参考曲目不豁免。
- 网易云音乐和 Beatport 纳入平台与链接要求的可选范围；平台不可用时透明标记，不伪造可用性。
- 动态内容优先级可包含风格、场景、熟悉度与发现感、时代与经典；其中熟悉度与发现感映射到 Popularity，时代与经典映射到 Freshness；平台顺序不参与内容权重。
- 简要版和丰富版在最终曲目深度核验阶段追查调性；只接受同一版本的可靠 DJ 商店或官方元数据，显示 `标准调名 / Camelot`，冲突或未知时显示“未知”。报告后可选按五度圈重排：基础 Camelot 兼容优先，实验性 ±2 仅兜底；丰富版只重排动态综合版，并最多提供 5 组需试听确认的 double drop 候选。
- 简要版和丰富版的“选歌碎碎念”各固定包含一条创意接歌建议；建议可自由选择曲目组合或 set 技巧，使用“可尝试”表达，不要求波形前置，不伪造试听或精确结构；极速版不显示该模块。
- 目标平台缺曲时按 preferred / exclusive 分层降级，不自动替代、不越权导出。
- 完整推荐报告后进入“下一步”：简要版和丰富版展示可选自然语言反馈、`导出txt` / `导出m3u8` 指令和五度圈排序邀请；极速版只展示前两项。私人记忆、反馈状态、缺失信息和来源仍后台记录，不在默认报告中展示。收到导出指令后按最终综合顺序（如已重排则按重排顺序）生成 UTF-8 文件，并透明记录无链接而跳过的曲目。
- 触发词覆盖 /迪歌、挖歌、找歌、排set、排歌单、setlist、crate digging 等挖歌与 DJ 编排表达；泛 playlist/歌单请求需要 DJ 或音乐策划语境。

## 目录

- `SKILL.md`：主工作流与安全边界
- `references/`：搜索验证、动态排序、报告模板和平台导出规则
- `evals/evals.json`：74 个行为评测，覆盖两轮需求收集、逐字模板与反引号回归、目标国家 / 地区、沟通语言与目标市场分离、熟悉度与发现感 / 时代与经典、平台发现与链接优先级、逐曲核验、自适应预算、极速版数量/分段/续跑/宿主降级/单通道/时间预算/三列表、中英文合同、Agent Skills 通用入口、能力缺失降级、Codex 适配层隔离、综合/四视图、报告级版本去重、报告后反馈/导出、调性来源、12 列表格、五度圈触发、重排范围、未知调性和 double drop 边界、创意接歌建议；`evals/intake-template-fixtures.json` 固化 Luna xhigh 压缩输出和 Sol medium 丢失行内代码的失败样例，`scripts/validate_intake_template.py` 从 `SKILL.md` 唯一模板源执行逐字校验；`evals/key-harmonic-fixtures.json` 固化 24 个 major/minor 到 Camelot 的标准映射与 BPM 归一化夹具。
- `evals/trigger-evals.json`：33 个触发与反触发样例
